# Pseudo-class
A CSS pseudo-class is a keyword prefixed with a single colon (:) that selects an element based on its current state, user interaction, or position in the document, without requiring an additional HTML class or JavaScrip


| Pseudo-class     | Meaning                                                |
| ---------------- | ------------------------------------------------------ |
| `:hover`         | Mouse is over the element                              |
| `:focus`         | Element has keyboard or mouse focus                    |
| `:active`        | Element is being clicked                               |
| `:visited`       | Link has been visited                                  |
| `:link`          | Link has not been visited                              |
| `:checked`       | Checkbox or radio button is selected                   |
| `:disabled`      | Form control is disabled                               |
| `:enabled`       | Form control is enabled                                |
| `:first-child`   | First child element                                    |
| `:last-child`    | Last child element                                     |
| `:nth-child(n)`  | Select the nth child                                   |
| `:not(selector)` | Select elements that do **not** match another selector |
